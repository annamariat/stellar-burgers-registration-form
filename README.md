# Stellar Burgers: форма регистрации

Форма регистрации контрибьюторов для космической бургерной Stellar Burgers. Сделана на React и TypeScript по готовым тестам: сначала были написаны тесты, а затем функциональность, при которой они все проходят.

Учебный проект курса «Фулстек-разработчик» в Яндекс Практикуме. Вёрстка страницы и тесты взяты из заготовки курса, логика формы написана мной.

## Что умеет форма

- Четыре поля: имя, e-mail, пароль и повтор пароля. Все поля взяты из UI-кита `@krgaa/react-developer-burger-ui-components`.
- Поля проверяются, когда пользователь уходит из них. При ошибке под полем появляется подсказка.
- Кнопка «Зарегистрироваться» неактивна, пока заполнены не все поля.
- При отправке форма проверяет, совпадают ли пароли.
- Если всё заполнено верно, вместо формы показывается экран успешной регистрации.

### Правила проверки

| Поле | Правило | Текст ошибки |
| --- | --- | --- |
| Имя | Только буквы (латиница или кириллица) и пробелы | Некорректный формат имени |
| E-mail | Формат `имя@домен.зона` | Ой, произошла ошибка! |
| Пароль | Не короче 6 символов | Некорректный пароль |
| Повтор пароля | Не короче 6 символов и совпадает с паролем | Некорректный пароль / Пароли не совпадают |

## Как устроено

Вся логика находится в компоненте [`src/components/form/form.tsx`](src/components/form/form.tsx):

- значения полей хранятся в одном объекте состояния;
- e-mail и пароль проверяют сами компоненты `EmailInput` и `PasswordInput`, а форма узнаёт результат через `checkValid`;
- для имени и повтора пароля проверка написана вручную. Повтор пароля сделан на базовом `Input` с иконкой показа пароля: только так можно вывести собственную ошибку «Пароли не совпадают»;
- после успешной проверки форма вызывает `setMode('complete')`, и родительский компонент `Content` показывает экран успеха.

## Запуск

```bash
npm install
npm run start
```

Приложение откроется на http://localhost:4000.

## Тесты

```bash
# Unit-тесты и snapshot (Jest)
npm run test

# Компонентные тесты (Playwright); перед первым запуском установите браузер
npx playwright install chromium
npm run test-ct
```

Все тесты проходят: Jest 2 из 2 (включая snapshot), Playwright 6 из 6.

Тесты Playwright проверяют:

- успешную отправку формы и показ экрана успеха;
- ошибку в имени;
- ошибку в e-mail;
- слишком короткий пароль;
- слишком короткий повтор пароля;
- несовпадающие пароли.
